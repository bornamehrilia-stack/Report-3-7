# گزارش پروژه: نمایش متن روی LCD  با آردوینو

## ۱. مقدمه  
در این پروژه، یک **نمایشگر LCD 16x2** به آردوینو متصل شده است و با استفاده از کتابخانه‌ی `LiquidCrystal`، متن‌هایی مانند “Hello world!” و شمارنده‌ی زمان (ثانیه) روی آن نمایش داده می‌شود. 



## ۳. قطعات مورد استفاده  
- برد آردوینو Uno  
- نمایشگر LCD    
- یک پاتنسیومتر ۱۰k اهم (برای تنظیم کنتراست LCD)  
- برد برد (Breadboard)  
- سیم‌های جامپر (jumper wires)



## ۴. نحوه‌ی ساخت مدار  
- **LCD**:  
  - پین 1 (VSS) → GND  
  - پین 2 (VDD) → 5V  
  - پین 3 (VO) → وسط پاتنسیومتر (برای تنظیم کنتراست)  
  - پین 4 (RS) → پین ۱۲ آردوینو  
  - پین 5 (RW) → GND (در حالت نوشتن)  
  - پین 6 (E) → پین ۱۱ آردوینو  
  - پین 7-10 (D0-D3) → نادیده گرفته می‌شوند (در حالت 4-bit)  
  - پین 11 (D4) → پین ۵ آردوینو  
  - پین 12 (D5) → پین ۴ آردوینو  
  - پین 13 (D6) → پین ۳ آردوینو  
  - پین 14 (D7) → پین ۲ آردوینو  
  - پین 15 (A) → 5V (با مقاومت ۲۲۰ اهم برای روشن کردن پس‌زمینه)  
  - پین 16 (K) → GND  
.

## ۵. کد برنامه:

```cpp
#include <LiquidCrystal.h>   // اضافه کردن کتابخانه LCD

// تعریف پین‌های LCD
const int rs = 12, en = 11, d4 = 5, d5 = 4, d6 = 3, d7 = 2;
LiquidCrystal lcd(rs, en, d4, d5, d6, d7);  // ایجاد شیء LCD

void setup() {
  lcd.begin(16, 2);   // شروع LCD با 16 ستون و 2 ردیف
  lcd.clear();        // پاک کردن صفحه
}

void loop() {
  lcd.setCursor(0, 0);           // قرار دادن کورسور در ابتدا ردیف اول
  lcd.print("Hello world!");     // نمایش متن

  lcd.setCursor(0, 1);           // قرار دادن کورسور در ابتدا ردیف دوم
  lcd.print(millis() / 1000);    // نمایش ثانیه‌های گذشته از شروع برنامه

  delay(1000);                   // تأخیر ۱ ثانیه برای ثبات نمایش
}
```


## ۶. نحوه‌ی کارکرد  
- پس از آپلود کد، LCD روشن می‌شود و متن “Hello world!” در ردیف اول و شمارنده‌ی ثانیه در ردیف دوم نمایش داده می‌شود.  
- شمارنده‌ی ثانیه هر ثانیه یک واحد افزایش می‌یابد.  
- اگر کنتراست LCD مناسب نباشد، با چرخاندن پاتنسیومتر، قابلیت خواندن متن را تنظیم کنید.

## ۷. نتایج  
LCD به درستی متن “Hello world!” و شمارنده‌ی ثانیه را نمایش می‌دهد. .
